# Interim
A GitHub Game Off 2026 entry by CyberSugar Studios. Theme: SHIFT.

Emily wakes in her home, unable to remember why her parents can't see her.
Shift between the realms to manipulate your surroundings and listen until the truth surfaces.

> Content warning: this game deals with suicide, grief, and family conflict.
> If you are struggling: call or text 988 (US) or visit findahelpline.com.

# Controls
| Key | Action |
|---|---|
| WASD / Mouse | Move / Look |
| E / F | Interact |
| Shift | Shift between planes |
| Space | Struggle |
| Esc / P | Pause |
